## Actionable Intelligence

### Autonomous Workflow Pattern
```yaml
multi_step_agent:
  trigger: "User request (e.g., 'post to LinkedIn')"
  steps:
    - step_1: "AI generates content"
    - step_2: "Run AI detection check (humanize if needed)"
    - step_3: "Request human approval"
    - step_4: "Auto-schedule/publish"
  human_checkpoints: ["approval_before_publish"]
```

### Spec-Driven Development Workflow
```markdown
Phase 1: SPECIFICATION (No coding)
  □ Write PRD.md
  □ Write ARCHITECTURE.md
  □ Write API.md
  □ Get human approval

Phase 2: IMPLEMENTATION (After approval)
  □ /build with approved spec
  □ Verify against spec
  □ Ship
```
