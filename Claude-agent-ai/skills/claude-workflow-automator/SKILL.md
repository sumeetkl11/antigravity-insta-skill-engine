# Claude Workflow Automator

> **Version**: 1.0.0  
> **Trigger**: Multi-step automation needed

---

## Purpose

Create autonomous multi-step agent workflows.

---

## Pattern

```yaml
trigger: "User request"
steps:
  1: AI generates content
  2: AI detection check (humanize)
  3: Human approval gate
  4: Auto-schedule/publish
```

---

## Examples

- LinkedIn content pipeline
- Social media automation
- Report generation workflow
